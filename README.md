# 待辦事項管理排程系統

## Proposal Report

### 動機與目標
在日常生活中有許多的待辦事項，我們需要記住並根據每項的重要程度、期限來安排先後。因此做出這個工具紀錄各事項，並根據事項的特性來安排順序，減少這些瑣事帶來的勞心勞力。

### 競品比較
市面上的類似競品如Microsoft To Do，已具備相當完整的功能。然而這些產品主要仍聚焦於「任務管理效率」，較少針對「使用者動機維持」進行設計。  
本專案新增的「獎勵機制」則補足了這一點差異。使用者可為每個待辦清單設定完成後的獎勵內容(如休息時間、娛樂活動或個人獎勵)，當該清單內所有任務完成時，系統會自動跳出獎勵提示，提供即時且具情緒回饋的正向強化。  
使用「獎勵機制」能夠讓使用者聚焦在任務上，提高完成任務的意願，正向回饋也有助於提高繼續使用本產品的意願。除了自我激勵，也能適用於家長以獎勵激勵孩子完成任務(如家事、功課)等情境。  

### 預期功能
- 新增todo list
- 新增/刪除待辦事項（名稱、截止時間、優先級） 
- 顯示所有待辦事項  
- 標記事項為已完成  
- 根據優先級與截止時間自動排序  
- 為每個todo list設置獎勵，並於完成所有任務時跳出  

### 使用技術
- 程式語言：Python  
- 開發工具：VS Code  
- 資料儲存：JSON 或 TXT

## Final Report

### 專案說明
在日常生活中有許多的待辦事項，我們需要記住並根據每項的重要程度、期限來安排先後。因此做出這個工具紀錄各事項，並根據事項的特性來安排順序，減少這些瑣事帶來的勞心勞力。  
與市面上的類似競品相比，本專案新增的「獎勵機制」，讓使用者可為每個待辦清單設定完成後的獎勵內容(如休息時間、娛樂活動或個人獎勵)，當該清單內所有任務完成時，系統會自動跳出獎勵提示，提供即時且具情緒回饋的正向強化。
可使用的功能
- 新增/刪除todo list
- 新增/刪除待辦事項（名稱、截止時間、優先級） 
- 顯示所有待辦事項  
- 標記事項為已完成  
- 根據優先級與截止時間自動排序  
- 為每個todo list設置獎勵，並於完成所有任務時跳出
- 提供不同排序演算法選擇(Timsort/Bubble/Heap)
- 對於不同演算法的效率比較，具體為優先級排序轉換成截止時間排序的花費時間
- 生成測試用資料

### 使用方式
執行 Todo List 系統  
-python main.py

產生測試資料(因已生成過一次，一般不須再執行)  
-python generate_sorted_data.py

執行演算法效能測試  
-python benchmark_sort.py

### 與課程的關聯總結
在演算法方面，本專案探討了不同排序演算法在實際應用情境中的效能差異。透過實作 Bubble Sort、Heap Sort 與 Python 內建 Timsort，並使用 Benchmark 測試不同資料量下的執行時間。  
由於相比於新增任務，改變優先級或截止時間後的自動排序顯然更花時間，因此測試的方法為生成不同數量，先以優先級再截止時間排序的資料，然後使用不同演算法排序成先以截止時間再優先級的順序，比較各方法與資料量所需的時間。

結果如下:  
| 資料量  | Timsort (s) | Bubble Sort (s) | Heap Sort (s) |
| ---- | ----------: | --------------: | ------------: |
| 100  |  0.00069400 |      0.04557120 |    0.00077600 |
| 500  |  0.00339090 |      1.16100320 |    0.00459090 |
| 1000 |  0.00686230 |      4.43684790 |    0.00763360 |
| 2000 |  0.01359360 |     18.25533900 |    0.01511440 |  

從結果可以觀察到，Timsort 與 Heap Sort 的表現明顯優於 Bubble Sort，而Timsort 與 Heap Sort 理論上的效率為O(n log n)，Bubble Sort則是 O(n²)，與觀察結果相呼應。另外也可以看到隨著資料量提升(n變大)，Timsort / Heap Sort 跟 Bubble Sort 的差距也越大。
